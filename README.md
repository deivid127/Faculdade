# Faculdade - Segundo Semestre

Este repositório contém todos os projetos e exercícios do meu segundo semestre na faculdade. O semestre é dividido em dois trimestres, cada um com suas respectivas disciplinas e projetos.

## Primeiro Trimestre

### Linguagem C
Na pasta `Aulas - linguagem C` você encontrará diversos exercícios implementados em C, incluindo:
- Calculadora de aumento salarial
- Sistema de gerenciamento de comida
- Implementação de contadores
- Exercícios de recursão

### Desenvolvimento WEB
Na pasta `Aulas - WEB` estão os exercícios e projetos relacionados ao desenvolvimento web, incluindo:
- HTML: Estruturação de páginas web
- CSS: Estilização e layouts flexíveis
- JavaScript: Validações e interatividade
- Projeto Zoológico: Site com informações sobre diferentes tipos de animais

### Sprint - Projeto Igreja
Na pasta `Sprint` está o projeto desenvolvido para uma instituição religiosa que realiza doações para a comunidade. O projeto inclui:
- Página inicial informativa
- Sistema de doações
- Formulário de contato
- Layout responsivo com HTML, CSS e JavaScript

## Portfólios
Na pasta `Portfólios` estão organizados os trabalhos finais dos alunos:
- Portfólio CAO
- Portfólio Nelson
